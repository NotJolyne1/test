Racing Thing in the browser, on your relay server
=================================================

Browsers can't send UDP, so the relay server needs one extra file that opens a browser
port (8080). It starts by itself. Your Unity/UDP side on 7777 doesn't change.

1. Put WebRelay.cs in your RelayNetworking.Server folder (next to Program.cs).
   Don't change Program.cs.
2. Put index.html in the same folder.
3. Run the server like always:  dotnet run
   You should see:  [Web] Browser players: open http://<this computer's address>:8080
4. Everyone opens  http://10.18.98.171:8080  -> Multiplayer -> Host or Join.

If you already changed things and it won't build, put the files in "original" back
(Program.cs and EventManager.cs go in RelayNetworking.Server) and delete any other
copies of Program.cs you added.
