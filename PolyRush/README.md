# PolyRush

Low-poly time trial racing, in the style of PolyTrack. There are 7 summer tracks with loops, jumps, bridges and boost pads, plus ghosts, medals and a full menu.

Made in Unity **2022.3.62f2**, using the Built-in render pipeline (it runs fine on school laptops).

## Opening it

1. Extract the zip. You get a folder with `Assets`, `Packages` and `ProjectSettings` in it.
2. In Unity Hub, go to **Add > Add project from disk** and pick that folder.
3. Open it and press **Play**. The game scene opens on its own the first time.

Build an exe with **PolyRush > Build Windows**. It goes to `Builds/Windows/`.

## Controls

| | |
|---|---|
| W / Up | Accelerate |
| S / Down | Brake and reverse |
| A D / Left Right | Steer |
| Space / Shift | Drift |
| Enter | Go back to the last checkpoint, keeping your speed |
| R | Restart |
| C | Camera |
| Esc | Pause |

The timer starts as soon as you press a key.

## Tracks

Tracks are text files in `Assets/PolyRush/Resources/Tracks`. Each line is one piece, and the pieces snap together on a 10 m grid:

```
name: My Track
theme: meadow        # meadow, coast, forest, lake, canyon, sunset, tropic
difficulty: 2

start
forward 3            # 3 tiles straight
right 2              # 90 degree turn, size 1-4 (bigger = wider)
left 3 bank          # banked turn
right 2 up=1         # turn that climbs one level (2.5 m)
up 2                 # climb 2 levels over 2 tiles ("steep" doubles it)
down 2
boost 2              # boost pad, 2 tiles long
cp                   # checkpoint
ramp                 # small kicker
gap 3 drop=1         # 3 tiles of air, landing one level lower
loop                 # full loop, comes out one tile to the right ("loop left" for the other way)
finish
```

Check a track after editing it. The checker reports overlapping pieces, tests the jumps at different speeds, and draws a little map:

```
python3 Tools/track_tool.py Assets/PolyRush/Resources/Tracks maps
```

## Sounds

The sounds in `Resources/Audio` are generated by `Tools/make_sounds.py` (it needs numpy and scipy). You can also drop in your own .wav files with the same names.

## Code

- `Core/Game.cs`: startup, menus, loading tracks
- `Race/Race.cs`: timing, checkpoints, respawning, ghosts
- `Car/CarController.cs`: driving physics. The numbers at the top are the ones to tweak.
- `Track/TrackPath.cs`: turns the track file into a 3D path
- `World/`: road, terrain and scenery meshes, all generated at load time

Multiplayer isn't in yet. The car only listens to `ICarInput`, and ghosts are a simple position/rotation recording, so a networked player can plug into both later.
