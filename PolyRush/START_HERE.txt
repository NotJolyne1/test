How to open PolyRush (Unity 2022.3.62f2)

1. Right-click PolyRush.zip > Extract All > Extract.
   You get a "PolyRush" folder with Assets, Packages and ProjectSettings inside.
2. Unity Hub > Projects > Add > "Add project from disk".
3. Pick that PolyRush folder and click Add Project.
4. Click it in the list to open. The first time takes a few minutes.
5. Press Play.

To make the exe: PolyRush menu > Build Windows. It ends up in Builds/Windows.
