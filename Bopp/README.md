# bopp.io

A 2D physics party game in one HTML file. Everyone is a ball; knock the others off the map.

Open `index.html` in any modern browser. No server, install or internet connection is needed.
To put it on a website, upload `index.html` as-is.

## Modes
Classic, Simple, Arrows, Death Arrows, Grapple, VTOL, Football.

## Keys
- Arrows / WASD: move
- X / Shift: heavy
- Z / Space: special (bow, grapple)
- Enter: chat, Esc: menu

## Notes
- Rooms are filled with bots for now; there is no real networking yet.
- The map editor saves to the browser's local storage. Your maps show up in the lobby map list when you host.
- Name, skin, XP and settings are also kept in local storage.
